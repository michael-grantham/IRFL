# Iteratively Reweighted Fused Lasso (IRFL)

This repository contains the research code for the *Iteratively Reweighted Fused Lasso (IRFL)* developed by **Michael Grantham** as part of his doctoral dissertation in Statistics at the University of Nebraska–Lincoln.

---

## Overview

IRFL extends the fused lasso by introducing adaptive reweighting of fusion penalties to improve changepoint recovery and model selection.  
The implementation builds on the [`genlasso`](https://cran.r-project.org/package=genlasso) package in R and supports simulation and empirical testing.
