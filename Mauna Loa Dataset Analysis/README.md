# Mauna Loa CO₂ Dataset — Chapter 5

This directory contains the code used in **Chapter 5** of the dissertation to reproduce the figures and analyses based on the **Mauna Loa atmospheric CO₂ monthly time series**, with changepoint detection performed using **IRFL**.

## Data Source

Monthly CO₂ data are obtained from the NOAA Global Monitoring Laboratory (GML):

https://gml.noaa.gov/ccgg/trends/data.html

## Purpose

The sole purpose of this code is to allow readers to **reproduce the images and results** involving the Mauna Loa CO₂ dataset presented in Chapter 5 of the dissertation.
