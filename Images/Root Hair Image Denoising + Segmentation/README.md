# Root Hair Image Denoising + Segmentation (IRFL)

This repository contains code for **denoising and segmenting root hair images** using IRFL.

The purpose of this repository is to enable **reproducibility of figures and experimental outputs** generated by the Root Hair Image Denoising + Segmentation scripts.

---

## Dataset attribution

Some images use the **DIRT/μ root hair image dataset** released by Pietrzyk et al. and hosted on Figshare.

Dataset link:  
https://figshare.com/articles/dataset/All_Supplement_zip/24886500/2  

DOI: **10.6084/m9.figshare.24886500.v2**

You will need the image entitled "DR-BT642-6-11012017-1_3 - EDF.tif" in your working directory to reproduce the image from the dissertation.
