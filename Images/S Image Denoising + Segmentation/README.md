# S Image Denoising + Segmentation (IRFL)

This repository contains code for **denoising and segmenting synthetic S-shaped images** using IRFL.

The scripts are designed to illustrate solution-path behavior, iterative reweighting effects, and edge/segmentation structure in a controlled, low-dimensional image setting.

---

## Data attribution

The S images used in this repository are **static screengrabs derived from figures in the generalized lasso literature**, specifically from work by Tibshirani and Taylor on solution paths for the generalized lasso.

Canonical reference:

Tibshirani, R. J., & Taylor, J. (2011).  
*The solution path of the generalized lasso*.  
**The Annals of Statistics**, 39(3), 1335–1371.  
https://doi.org/10.1214/11-AOS878

The images are used **solely for methodological illustration** of denoising and segmentation behavior.

---

## Reproducibility

All denoised images, iteration panels, and edge/segmentation overlays shown in this dissertation can be reproduced directly using the scripts in this repository and the included PNG files.

All parameters, iteration counts, and plotting logic are explicitly specified to ensure reproducibility.
